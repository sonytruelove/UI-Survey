# Бренд-бриф: «ЭнергоСетьСтрой» — демо корпоративной системы заявок

> Учебный проект для сравнения UI-китов. Визуальный стиль вдохновлён сайтом
> energosetstroy.pro (энергетическая/электромонтажная EPC-компания, РФ).
> Не является официальным сайтом компании, логотип — абстрактный плейсхолдер,
> а не копия оригинального знака.

Этот файл — единственный источник истины для ВСЕХ страниц под разные UI-киты.
Каждая страница должна визуально соответствовать этим токенам и реализовывать
ровно один и тот же набор экранов/контента (см. раздел «Контент страницы»),
но собственными нативными компонентами конкретного кита.

### Типографика

- **Заголовки / лого / крупные цифры (display):** жирный, геометричный,
  слегка «индустриальный» шрифт в верхнем регистре. Google Fonts: **Rajdhani**
  (600/700). Если кит тянет свой дефолтный шрифт заголовков — переопределить
  через `font-family: 'Rajdhani', <fallback-кита>` для H1/H2/лого/крупных чисел KPI.
- **Основной текст / формы / таблицы (body):** **Inter** (400/500/600),
  через Google Fonts CDN. Это касается лейблов, инпутов, ячеек таблицы —
  Rajdhani только для заголовков и акцентных чисел, не для длинного текста.
- Заголовки — `text-transform: uppercase; letter-spacing: .02em;`.

Подключение шрифтов (одинаково на всех страницах):
```html
<link rel="preconnect" href="https://fonts.googleapis.com">
<link href="https://fonts.googleapis.com/css2?family=Rajdhani:wght@500;600;700&family=Inter:wght@400;500;600;700&display=swap" rel="stylesheet">
```

### Прочее

- **Радиусы:** карточки/таблицы/модалки — `12px`; инпуты/кнопки/бейджи — `8px`;
  маленькие теги-приоритеты можно `999px` (pill).
- **Тени:** мягкие, `0 1px 2px rgba(16,16,16,.06), 0 8px 24px rgba(16,16,16,.06)` на карточках/модалках.
- **Лого:** `/home/user/UI-Survey/shared/logo.svg` (абстрактная концентрическая
  «мишень», `stroke: currentColor`) + текстовый wordmark рядом двумя строками
  заглавными буквами: **«ЭНЕРГО»** / **«СЕТЬСТРОЙ»** шрифтом Rajdhani 700,
  на тёмном фоне — белым, `letter-spacing` небольшой, `line-height: .95`.
  Скопируйте `logo.svg` в свою папку кита (`kits/<kit>/logo.svg`) или заинлайньте.

## 2. Layout (общий для всех китов)

Классический admin-shell:

```
┌───────────────────────────────────────────────────────────┐
│  HEADER (bg-dark, высота ~64px, фикс.)                     │
│  [лого+wordmark]      [поиск]      [🔔] [+ Новая заявка] [👤 ФИО / должность] │
├───────────┬───────────────────────────────────────────────┤
│ SIDEBAR   │  CONTENT (bg-app)                              │
│ (bg-dark, │  Заголовок страницы «Заявки» + хлебные крошки  │
│ ~250px)   │                                                 │
│ • Дашборд │  [4 KPI-карточки: Всего / В работе / Выполнено /│
│ • Заявки ●│   Просрочено]                                  │
│ • Объекты │                                                 │
│ • Исполн. │  Тулбар: поиск • фильтр Статус • фильтр        │
│ • Отчёты  │  Приоритет • фильтр Объект • [+ Новая заявка]  │
│ • Настройки│                                                │
│           │  Таблица заявок (см. ниже) + пагинация          │
└───────────┴───────────────────────────────────────────────┘
```
Пункт «Заявки» — активный (выделен `--accent`). Иконки в сайдбаре — из
иконочного набора, который штатно идёт с этим UI-китом (Bootstrap → Bootstrap
Icons, Ant → Ant Design Icons, Element Plus → Element Plus Icons, и т.д.;
если у кита нет своих иконок — Bootstrap Icons или inline SVG).

### KPI-карточки (4 шт.)
1. Всего заявок — **128** (нейтральная/акцент)
2. В работе — **34** (accent)
3. Выполнено — **81** (success)
4. Просрочено — **7** (danger)

«Объект», кнопка **+ Новая заявка** (primary, accent) — открывает форму
создания (модалка/drawer).

### Форма «Новая заявка» (модалка или drawer справа, по нативному паттерну кита)

6. **Срок выполнения** — date picker
7. **Описание заявки** — textarea, placeholder «Опишите характер работ, адрес, особые условия…»
8. **Вложение** — file input («Прикрепить фото/схему»)
9. Кнопки: **Отмена** (secondary) / **Создать заявку** (primary, accent)

## 3. Технические требования к каждой странице

- Один самодостаточный файл `kits/<slug>/index.html`. Никаких сборщиков —
  только CDN `<script>/<link>` теги (unpkg/jsdelivr/cdnjs) + инлайновые
  `<style>`/`<script>` для кастомизации. Должен открываться прямо в браузере.
  Если конкретный кит (Vue-based) требует минимальной инициализации
  (`Vue.createApp(...).mount(...)`) — это ок, лишь бы всё грузилось с CDN
  без npm install/build.
- Используйте **нативные компоненты кита** (его карточки, таблицы, бейджи,
  модалки, селекты, датапикеры), а не голый HTML поверх кита — цель именно
  показать, как выглядят и ведут себя родные компоненты этой библиотеки.
- Обязательно переопределите цвета кита под токены из раздела 1 (через CSS
  переменные/SCSS-подобные оверрайды/theme-config кита — где что доступно) —
  primary/accent-цвет кита = `--accent` (#E07B3E), а не дефолтный
  синий/фиолетовый. Это самое важное для честного визуального сравнения.
- Ширина: рассчитано на десктоп ≥1280px, адаптивность необязательна.
- В самом низу страницы — тонкая служебная плашка (мелкий серый текст):
  `Kit: <Название> vX.Y.Z · CDN: <ссылки> · Icons: <какой набор иконок>`.
- НЕ запускать git-команды и не трогать файлы вне своей папки `kits/<slug>/`.
- Русский язык интерфейса везде.
