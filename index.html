UI-Kit Survey — «Заявки»

Одна и та же корпоративная система создания заявок (энергетическая/электромонтажная тематика), собранная 10 раз — под 10 разных UI-китов, по единому дизайн-брифу (цвета, шрифты, макет, состав экранов). Цель — визуально сравнить, как одна и та же задача выглядит и ощущается в разных библиотеках, чтобы быстрее выбирать подходящий кит под конкретный проект. Каждая страница адаптирована под мобильные экраны.

📄 Сравнительное исследование (плюсы/минусы, icon-киты) 🎨 Бренд-бриф / дизайн-токены

CSS-фреймворки и классические компонентные киты (vanilla)

Bootstrap 5
CSS + JS · Vanilla
Самый узнаваемый фреймворк в индустрии, огромное community, низкий порог входа.
Иконки: Bootstrap Icons
Bulma
CSS-only (Flexbox/Grid)
Чистый CSS без JS, современный вид, лёгкая кастомизация через HSL-переменные.
Иконки: Font Awesome
Materialize CSS
CSS + JS · Material Design 1
Классический Material Design без React/Angular, простая семантика классов.
Иконки: Material Icons
Fomantic-UI
CSS + jQuery
Форк Semantic UI, «человекочитаемая» разметка, богатый набор компонентов.
Иконки: встроенный icon-font
Tailwind CSS + DaisyUI
Utility-first + компонентный слой
Полный контроль над стилем через утилиты + готовые компоненты DaisyUI поверх.
Иконки: Heroicons
