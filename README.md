# UI-Survey

Учебный проект: одна и та же корпоративная система создания заявок
(«ЭнергоСетьСтрой» — вымышленное демо в стилистике energosetstroy.pro,
энергетическая/электромонтажная EPC-компания) реализована 11 раз — под 11
разных UI-китов, по единому дизайн-брифу. Цель — быстро сравнивать
«ассортимент» UI-библиотек глазами и знать их плюсы/минусы для агентного
прототипирования интерфейсов под разные проекты. Все страницы адаптированы
под мобильные экраны.

## Как смотреть

Откройте [`index.html`](index.html) — это галерея со ссылками на все 11
страниц (сгруппированы по экосистемам: vanilla CSS/JS, Web Components,
Vue-экосистема, React-экосистема). Каждая страница — самодостаточный
`index.html`, который подключает свой UI-кит только через публичный CDN
(jsDelivr/unpkg/cdnjs/esm.sh), без сборки — можно просто открыть файл в
браузере или уменьшить окно/зайти с телефона, чтобы посмотреть мобильную
раскладку.

- [`shared/brand.md`](shared/brand.md) — бренд-бриф/дизайн-токены (цвета,
  шрифты, макет, состав экранов), которому следуют все 10 страниц.
- [`shared/responsive.md`](shared/responsive.md) — спецификация мобильной
  адаптации (брейкпоинты, поведение сайдбара/KPI/таблицы/формы).
- [`RESEARCH.md`](RESEARCH.md) — сравнительный обзор UI-китов (плюсы/минусы,
  адаптивность, когда что выбирать) и обзор icon-китов.

## Собранные киты (`kits/`)

| Кит | Экосистема |
|---|---|
| Bootstrap 5 | CSS+JS vanilla |
| Bulma | CSS-only |
| Materialize CSS | CSS+JS, Material Design 1 |
| Fomantic-UI | CSS+jQuery |
| Tailwind CSS + DaisyUI | Utility-first |
| Shoelace | Web Components |
| Fluent UI Web Components | Web Components (Microsoft) |
| Vuetify 3 | Vue 3, Material Design |
| Element Plus | Vue 3, Enterprise |
| HeroUI (бывший NextUI) | React, Tailwind + React Aria |
| VK UI | React, мобильный дизайн-язык ВКонтакте |

Carbon Design System, PrimeVue и Ant Design Vue были в первой версии
подборки, но их CDN-only реализация получилась заметно кривой — страницы
убраны из демо-набора (сами киты остаются в обзоре в `RESEARCH.md` — они
полноценные и стоящие знакомства, просто не через голый CDN).

## Важная оговорка

Страницы собирались и проверялись в песочнице с ограниченным сетевым
доступом (egress-политика блокирует прямые запросы к CDN-доменам вроде
jsdelivr/unpkg/cdnjs из этой среды), поэтому CDN-ссылки **не были живьём
протестированы в браузере** здесь — они основаны на реальных, задокументированных
путях пакетов (версии/экспорты/CSS-токены сверены через jsDelivr/GitHub API,
где это было возможно из песочницы). `kits/heroui` и `kits/vkui` — два самых
технически рискованных из одиннадцати (оба — React через esm.sh + Babel-in-browser
без сборщика), поэтому в обоих специально заложены запасные варианты
(fallback-иконки на случай нерезолвящегося имени, error boundary, у HeroUI —
ещё и ручные CSS-токены цвета на случай проблем с Tailwind-плагином темы) —
страницы должны остаться презентабельными даже если что-то из экзотической
части стека не подгрузится идеально. Если что-то не отрендерилось как надо —
дайте знать, поправим.

Логотип — абстрактный плейсхолдер (не копия реального логотипа компании),
контент вымышленный, страницы не являются и не выдают себя за официальный
сайт energosetstroy.pro.
